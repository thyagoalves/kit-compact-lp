# Kit Compact 2 — Landing Page

Landing Page responsiva e interativa de alta performance para o **Kit Compact 2** (Teclado e Mouse sem fio), desenvolvida com arquitetura modular VTEX-safe, flipbook interativo 100% CSS puro para medidas técnicas e visualizadores dinâmicos.

## 🚀 Tecnologias e Recursos
- **HTML5 & CSS3 Puro**: Animação frame-a-frame de 32 passos via sprite strips WebP controladas via CSS `:checked ~`.
- **Medidas Técnicas Interativas**: Cotas dimensionais dinâmicas para vistas superior, frontal e lateral do teclado e do mouse.
- **Micro-interações Apple Style**: Switch morfológico líquido para troca de cores (Preto e Branco) e carrosséis responsivos.
- **Zero Dependências Pesadas**: Desenvolvido para máxima velocidade de carregamento e compatibilidade com CMS VTEX.

## 📦 Estrutura do Projeto
- `KitCompact.html` / `index.html`: Arquivo principal da Landing Page.
- `assets/`: Imagens em alta resolução, vídeos demonstrativos e strips WebP otimizadas para o flipbook.
